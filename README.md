# SkillSync

SkillSync is a Core Java based student skill-matching application.

## Project Overview

SkillSync allows students to create their profiles by adding:

- Name
- College
- Course
- Year
- Bio
- Skills

Students can then search for other students based on their skills.

## Features

- Add Student
- View All Students
- Search Student
- Update Student
- Delete Student
- Find Skill Match
- Add New Skills
- File-based Data Storage
- Persistent Student Data
- Simple Web Frontend
